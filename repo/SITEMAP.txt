Generated 9 September 2026. Reflects the app as of this date; if pages

HOW TO READ THIS FILE
Each entry below is one real page. "URL" is the actual route a browser
visits. "Copy source" tells you where the WORDS on that page actually
come from — either written directly in the page's own code file (so
you'd need to edit the .tsx file itself, in a text/code editor, to
change wording), or pulled live from a real Google Sheet tab (so you
can just edit the sheet, no code change needed, and it updates the
next time the page loads).

Every [clubToken] in a URL is the club's own private token from their
dashboard link, e.g. /dashboard/hkfc-x7Kq2mZ9pR4wT8vN3sJ6/outreach/players.

================================================================
PART 3 — LEGAL PAGES (POPUP, NOT A SEPARATE URL)
================================================================
These don't have their own web address — they open as a pop-up from
the footer link on any page, so there's no URL to list. The words
themselves are the easiest copy in the whole app to edit: each one is
a single, plain block of text in its own file, written in plain
English with no code to work around.

Privacy Policy   → lib/legal/privacy-policy.ts
Terms of Service → lib/legal/terms-of-service.ts
Cookie Policy    → lib/legal/cookie-policy.ts

The little popup itself (the box these appear in) is built in
components/legal-modal.tsx, and the three footer links that open it
are in components/legal-links.tsx — you shouldn't need either of
those just to change wording, only the three files above.


================================================================
PART 4 — WHERE THE REAL GOOGLE SHEETS ARE
================================================================
The app pulls live data from three separate Google Sheets workbooks.
Which one a page uses is noted against each page above.

THE ULTIMATE NBRH CLUB HOUSE OS DATABASE
  Real tabs used: DASHBOARD (X), NEIGHBOURS (O), PEOPLE,
  CONTENT CREATORS, BRANDS, BUSINESSES, INFLUENCERS, KIT,
  SOCIAL VENUE, SPONSORSHIPS, FUNDING, OPPORTUNITIES.
  This is also where the "U notes" column lives on every one of these
  tabs — the column you fill in with a club's real Club ID to
  recommend that row to them on their Overview page.

CHOS Workspace
  Real tabs used: INBOX, TRENDING TOPICS, FROM THE NBRH, RESOURCES,
  FAQs, PERKS, CALENDAR, SERVICES, PLAN, NOTIFICATIONS, HEADER.

Club Hub
  Real tabs used: Dynamic Club Page Hub.

(The app finds each workbook via its ID, set in Vercel's Environment
Variables as GOOGLE_SHEET_ID_MASTER, GOOGLE_SHEET_ID_WORKSPACE, and
GOOGLE_SHEET_ID_CLUB_HUB. You shouldn't need to touch these unless a
whole workbook is ever swapped out for a new one.)
