# Onboarding & first-run flow

Layer in once Overview + Outreach both pass Definition of Done. Extend as later sections ship.

**Guided first run (3 steps, dismissible, resumable):**
1. Set your priorities (priorities-capture form; becomes full triage once D10 ships)
2. See your first personalised recommendation (Top 5 panel highlights)
3. Try your first outreach action (Outreach opens with a spotlight on one high-match entry; the one-off token explainer fires here)

State stored per club (`Clubs.onboarding_step` — add to schema when building this). Everything else remains explorable throughout; the flow is a path, not a cage.

**Token education:** first-ever token encounter → one-off modal: what a token is (a unit of NBRH's hands-on time), current balance, where the balance always lives. Never shown twice.
